In Stash

Install the moansubs plugin. Every scene page gets a Subtitles panel, already pointed at this site.

In Stash: Settings → Plugins → Available plugins, add the moansubs source, install moansubs, reload. Details on the plugin page.

Without Stash

MoanDrop is a small desktop app. Drop a video or a folder on it and the subtitle lands next to the file. The video never leaves your machine.

Share yours

Upload a subtitle you made or found. Votes decide which track comes first for each scene.
