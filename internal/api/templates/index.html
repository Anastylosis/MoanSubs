How it works

The plugin asks with the scene's oshash and phash, which Stash already computed. A different encode of the same scene still matches; a sidecar lands next to the file, ready to play.

Get the plugin

In Stash: Settings → Plugins → Available plugins, add the moansubs source, install moansubs, reload. Details and the manual install are on the plugin page.
